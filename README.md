## 📋 Sobre este Portfólio

Este é um site de portfólio moderno e minimalista, desenvolvido para apresentar o meu trabalho como programador. O site exibe os meus projectos, competências e experiência profissional num formato limpo, visualmente apelativo e que funciona perfeitamente em todos os dispositivos.

---

## ✨ Funcionalidades

### 🎨 **Design Moderno**
- Estética limpa e minimalista com um toque profissional
- Layout responsivo que se adapta a todos os tamanhos de ecrã
- Animações suaves e transições para uma experiência envolvente
- Tipografia optimizada para leitura

### 📂 **Galeria de Projectos**
- Curadoria dos meus projectos de desenvolvimento
- Cada projecto inclui descrição, tecnologias utilizadas e links ao vivo
- Cartões visuais com capturas de ecrã dos projectos

### 👤 **Secção Sobre Mim**
- Apresentação profissional e biografia
- Competências e tecnologias com que trabalho
- Filosofia pessoal e abordagem ao desenvolvimento

### 📞 **Contacto**
- Link direto para email
- Ligações para redes sociais (GitHub, LinkedIn, etc.)
- Oportunidades de networking profissional

### ⚡ **Performance Otimizada**
- Carregamento rápido com recursos optimizados
- HTML semântico para SEO
- Considerações de acessibilidade
