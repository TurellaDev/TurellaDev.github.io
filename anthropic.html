Anthropic API Key Checker

Paste a key to verify it's valid. The key is sent directly from your browser to Anthropic's API — it is never stored or sent anywhere else.

Usage tier & rate limits
This runs one minimal request (1 output token) against the Messages API to confirm the key authenticates, which costs a fraction of a cent. Nothing is logged or persisted by this page — reload and it's gone.

Note on "plan": a standard API key (sk-ant-api03-...) has no endpoint that returns a plan name. What's actually knowable per-request is the org's usage tier (Start / Build / Scale / Custom) via response headers — that's a separate system from Claude.ai subscriptions (Free/Pro/Max/Team/Enterprise), which API keys aren't part of at all. The authoritative view is the Console's Limits page.
